## 1. 一覧カード（買い・売り推奨）の改訂

### 1.1 旧 → 新
- 旧：左に総合スコア（例 84/100）、右にティッカー・サマリー。
- 新：左に **GENDOインジケーター**、右にティッカー・サマリー・**MAGIミニインジケーター**。総合スコアは廃止。

### 1.2 GENDOインジケーター（カード左）
- 構成：碇アバター（円・明朝「碇」）＋ 日本語一語 ＋ `GENDO` ラベル（mono）。
- 横マージン広め、縦罫線で本体と区切る（独立した「構え」として見せる）。
- 一語の語彙（命令形を避け「構え」とする）：

| 文脈 | GENDO 一語 | 色 |
|---|---|---|
| 買い・3審判一致 | 推し | up（緑） |
| 買い・割れ | 要検討 | up（緑） |
| 利確サイン | 利確 | sub（ティール） |
| 損切りサイン | 撤退 | down（赤） |
| 保有継続 | 静観 | ink-2（中立） |

### 1.3 MAGIミニインジケーター（カード中・サマリー下）
- 3審判を **固有名主・役割従** で表示：`MELCHIOR 業績 買` / `BALTHASAR 株価 慎重` / `CASPER 文脈 買`。
- 各審判に色ドット（業績=key橙 / 株価=sub青緑 / 文脈=warn黄）。判定が非アクティブ（保留・慎重）はドット opacity 下げ。
- 右端に割れ方（mono）：`2/3 買い・割れ` 等。
- フォント：固有名は明朝、役割・判定はゴシック。

### 1.4 一覧で総合スコアを出さない理由
3審判を1点に統合する嘘を避ける。GENDO の一語は「碇という判断者の構え」であり統合スコアではない。
必ず MAGIミニ（3審判の根拠）とセットで表示し、一語が独り歩きしないようにする。

## 2. 詳細パネルの MAGI 決裁ブロック（新規）

詳細パネル本文の冒頭サマリー直後に、1セクションとして挿入。上から「事実→相談→検証→決断」。

### 2.1 MAGI 判定ゾーン（事実）
- 鼎立図：中心（MAGIコア）から3審判へ結線。各ノードは六角形＋略号（業/株/文）。
  - ステータス表現：買い/売り判定=塗りつぶし点灯、保留/慎重=点線・半輝。図単体で割れが分かる。
- 3審判リスト：**役割主・固有名従**（一覧と逆）。「業績」大（ゴシック）、「MELCHIOR・1 / FUND」小（明朝）。
  各行 = 色タグ｜役割名＋固有名｜判定｜根拠文（実データ照合済みの旨を含む）。
- フッタ：割れ方 ＋ `SCORE: NONE`（総合スコアを出さない明示）。

### 2.2 碇司令ゾーン（相談）
- 碇アバター＋「碇司令」＋「判断アシスト」。名前・発言は明朝。
- 推奨文：方向＋簡潔な理由。
- 反対論拠：「反対するなら：」で始め、**必ず併記**（省略不可）。左罫線 warn 色のボックス。
- 根拠注記：「3審判の判定のみ。新たな事実は加えていない。予測グラフの数値は推奨の根拠にしていない」。

### 2.3 検証＋決裁ゾーン（決断）
- 検証フラグ3種（sub色チップ）：①数値 全照合済（時点明記）②信用性 問題なし/警戒 ③碇発言 MAGI準拠。
  - 未照合があれば該当フラグを警告色にし、決裁ボタンの既定を「保留」に。
- 決裁ボタン：文脈で変化。買い=承認して発注へ（key橙）/否認/保留。利確=利確を承認（sub）/半分だけ利確/保留。
  損切り=損切りを承認（down）/1日待つ/保留。
- ヒント：「（割れている審判）の反対論拠を読んでから決裁してください」。

### 2.4 グラフ（既存流用）
- 買い：3シナリオ予測（強気/ベース/弱気）。保有：予測vs実績。**既存のものを流用**。
- 予測値には「この予測値はモデル生成・未照合（参考）」バッジを付す。CHART/MAGI のタブ切替は任意 `[未確定]`。

## 3. フォント方針（PANEL_SPECS デザインシステムへの上書き）
- 既存「明朝完全禁止」を限定解除（親 §3.1 参照）。
- ゴシック：Noto Sans JP（既定・全要素）。明朝：Noto Serif JP（審判固有名・碇の名・碇の発言のみ）。数値英字：JetBrains Mono。
- 配色は既存トークン踏襲（--key 橙 / --sub 青緑 / --up 緑 / --down 赤 / --warn 黄）。新規色を作らない。

## 4. エッジケース（既存 PANEL_SPECS のエッジケース節に追加）
- 審判が判定不能（データ欠損）：当該審判を「判定不能」と表示。推測で埋めない。図ノードは灰で点滅なし。
- 3審判全会一致：確信度高だが「全員同方向に誤った可能性」をフッタに併記。
- 碇が MAGI 外を創作：検証フラグ③が赤。碇ゾーンに警告表示。
