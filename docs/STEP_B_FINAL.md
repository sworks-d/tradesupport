## 0. ダッシュボードの設計原則

### コア原則：「今すべきこと > 現状情報」

毎朝開いて 3〜5 分で判断完結する。深掘りしたい時は 15〜30 分も対応可能。

```
情報の優先順位（上から）
├── 売り推奨（利確・損切り）  ← 最優先・時間的緊急性が高い
├── 買い推奨（新規候補）      ← 機会捕捉
├── 警告・決算予定           ← 注視レベル
├── 保有銘柄の進捗           ← 現状把握
├── 予測の検証 / 手動投入    ← AIの信頼性確認・補助
└── 収集トピックス           ← 背景情報・読みたい時に読む
```

### 副次原則
- **直感的に分かる**：数字より形（グラフ）で判断
- **透明性**：AIの判断根拠が見えること（トピックス、シナリオ進捗、目標期間）
- **規律**：感情に振られない構造（機械的な売り推奨、損切りルール明示）
- **時間軸の正確性**：銘柄ごとの目標期間を尊重、統一しない

## 2. サイドバー（280px、状況サマリーを集約）

### 役割
**ツール全体のサマリーパネル** として、ナビゲーション以上の情報集約機能を持つ。
- 旧版にあった「上部のステータスバー」と「下部のメタスタッツ」を廃止し、ここに統合

### 構成（上から）

| ブロック | 内容 |
|---|---|
| ロゴ + Live インジケータ | システムが稼働中であることを示す |
| 総資産 | 大きく ¥108,420、今日の変化（緑/赤）、30日推移ミニ折れ線、累計リターン、最終更新時刻 + 更新ボタン |
| 配分 | 横棒バー4本（米国株／日本株／サテライト／現金）。Core-Satellite 管理用。ドーナツチャートは廃止 |
| 今日のサマリー | 売り推奨／買い推奨／警告／的中率／月次コスト（バー付き）|
| ナビゲーション | Today / 分析 / 予測の検証 / 設定 の4セクション |

### 設計判断

- **月次コストはバー化**：「予算の何%使ったか」が形で分かる

### 3.2 最優先：今すべきこと（売り × 買い、上下2カラム）

#### 売りゾーン（左）

各カード（クリックで詳細パネル展開）：

| 状態バッジ | 利確（ティール）/ 損切り（赤） |
| スコア | 利確スコア91、損切りスコア78 等 |

### 3.3 注視すべきこと（警告 × 決算予定、左右2カラム）

#### 警告
- 売り推奨に至る前の予兆銘柄を表示
- 例：「MSFT シナリオ進捗が鈍化」

#### 決算予定
- 今週・来週の決算予定（保有銘柄と買い候補で重要なもの）
- 「AAPL · 5/22 (木) 引け後 · 保有銘柄」のように対象を明示

### 3.4 保有銘柄 · 予測 vs 実績（3カラム）

5銘柄を3カラムグリッドで表示。

各カードの構成：

| 要素 | 内容 |
|---|---|
| 状態縦線 | カード左端の色付き縦線（緑/黄/赤/ティール） |
| ラベル群 | [状態] [戦略・期間] [市場・セクター]の3つのバッジ |
| ティッカー、銘柄名、価格、損益 | 「AAPL Apple Inc.  $215.30  +5.2%」 |
| 仮説 | 「Vision Pro と AI機能で買い替え加速、サービス売上+18%」 |
| グラフ | 銘柄ごとの目標期間で描く（後述） |
| 進捗ステータス | 「進捗 10% · 残り 326日 · 順調」 |

#### グラフの構造（重要、STEP B で最終確定）
- X軸：**取得日 → 目標日**（銘柄ごとに違う）
- Y軸：% リターン（共通スケール -10〜+20%）
- **「今」の位置**：経過日数 / 全期間 で決まる（進捗% で右寄り or 左寄り）
- 過去（取得→今）：**実線**
- 未来（今→目標）：**点線 + 半透明の帯**（予測のレンジ）
- 目標ライン：**グレーの水平点線**
- 現在地：**脈動マーカー + ラベル「今 +5.2%」**

#### 銘柄ごとの目標期間（サンプル）

| 銘柄 | 戦略カテゴリ | 期間 | 経過 | 進捗 |
|---|---|---|---|---|
| AAPL | 長期 | 1年 | 39日 | 10% |
| MSFT | 中期 | 6ヶ月 | 39日 | 22% |
| TSLA | 中期 | 3ヶ月 | 36日 | 40%（シナリオ崩壊） |
| 7203 | 中期 | 6週間 | 33日 | 78%（利確圏） |
| 6920 | 中期-長期 | 6ヶ月 | 26日 | 14% |

#### 状態の判定
- **順調（緑）**：実績が予測ラインに沿っている、目標達成見込み
- **注視（黄）**：実績が予測から下方乖離、決算等の節目で再評価必要
- **危険（赤）**：シナリオ崩壊、損切りライン接近、売り推奨に切り替わる候補
- **利確圏（ティール）**：目標株価到達寸前、利確推奨に切り替わる候補

### 3.5 予測の検証と補助（左：Track Record / 右：手動投入）

#### Track Record（左、7カラム）
- 統計4枚（的中率68% / 平均リターン+4.8% / スコア相関0.62 / S&P500との差+2.3pt）
- **累積リターン推移グラフ**：
  - オレンジ実線：実績の累積
  - オレンジ点線：予測の累積
  - ティール実線：S&P 500（ベンチマーク）
  - **各点 = 個別レコメンド1件**（緑=的中、赤=外れ）、ホバーで「04-23 AAPL 買い +5.2% 的中」表示

#### 手動投入（右、5カラム）
- テキストエリア：X発言、記事URL、銘柄コードなどを投入
- 「分析する」ボタン + コスト目安（「Claude Sonnet · 1回約 ¥3」）
- 最近の投入履歴（直近2-3件）

### 3.6 収集したトピックス（最下部、重要度+時系列ソート）

#### 役割
**AIの判断の透明性確保**。朝バッチで AI が読んだ記事・IR・X発言などを表示。

#### タブ
- すべて 12 / マクロ 3 / 業界 4 / 個別 5

#### 各トピックの構成

| 要素 | 内容 |
|---|---|
| 重要度バッジ | 重要（赤）/ 中（黄）/ 低（グレー） |
| 時刻 | 「2h前」「1d前」 |
| 見出し | 「Tesla、FSD収益化遅延報道 — 規制当局がレベル4認可に慎重姿勢」 |
| 要約 | 1-2行で要約 |
| ソースリンク | Bloomberg, Reuters, 日経, EDINET 等への外部リンク（複数可）|
| タグ | 銘柄ティッカー（オレンジ）、市場、業界 |
| 影響 | 「TSLA 損切り推奨の根拠の一つ・シナリオ崩壊を補強」 |

#### ソート順
**重要度順 → 同重要度内は新しい順**

## 4. インタラクション設計

### 4.1 詳細パネル（クリックで右からスライドイン）
売り買いカードのクリックで開く。820px幅。ESCで閉じる。

#### 買い候補の詳細パネル構成（8セクション）
1. ざっくり言うと（要約、最上部に目立つ位置）
2. スコアの内訳（4軸：ファンダメンタル/テクニカル/ニュース/AIの確信度）
3. なぜ買うべきか（3つの根拠）
4. リスクは何か（3つの負けパターン）
5. 3つのシナリオ（強気/ベース/弱気 + 期待リターン）
6. ファンダメンタル（PER、EPS、業界平均比較付き）
7. 直近のニュース（5件、ポジ/ネガ/中立判定）
8. 過去の類似ケース（同スコア帯の的中率）
9. moomooで買う準備（4ステップ + コピー可能フィールド）

#### 売り（利確）の詳細パネル構成
1. ざっくり言うと（売り：利確）
2. 利確スコアの内訳（目標達成度/シナリオ達成度/テクニカル悪化/AIの確信度）
3. なぜ売るべきか（3つの根拠）
4. 売らないとどうなる？（持ち続けるリスク）
5. 3つの選択肢（全て売る / 半分売る / 持ち続ける）
6. 当初の仮説と現状（買った時の仮説 vs 今の数字）
7. 過去の類似ケース（切った vs 持ち続けた結果比較）
8. moomooで売る準備

#### 売り（損切り）の詳細パネル構成
売り（利確）と同じ構造、ただし：
- スコア内訳の軸が変わる（シナリオ崩壊度/テクニカル悪化/ニュース悪化/AIの確信度）
- 「感情的な判断で傷を広げる典型パターン」への明示的言及
- FXで「感情に振られる」経験を引用するメッセージ
- 売却ボタンが赤色

### 4.2 ホバーツールチップ
- 保有銘柄グラフの各データ点：「AAPL · 04-28 / 実績 +1.8% / 予測 +2.8%」
- Track Record の各点：「04-23 / AAPL / アクション 買い / 結果 +5.2% 的中」

### 4.3 価格更新ボタン
- ヘッダー右上に大きく配置
- サイドバーの総資産下にも小さく配置
- 押すと：
  - ↻ アイコンが回転（0.7秒）
  - 価格セルが緑/赤にフラッシュ
  - 「最終更新」が「たった今」にリセット
- 自動更新はしない（中期投資なので秒単位リアルタイムは不要）

## 6. 競合分析との位置づけ

### ベンチマーク調査結果（STEP B 前半で実施）

#### 国内ツール
- moomoo：AI機能5つ持つ最大競合だが、APIで取れない
- ロボフォリオ、カビュウ、Yahoo!ファイナンス：保有資産管理が主目的、判断支援は弱い

#### 海外参考
- **Linear**：アクション駆動UI、最小装飾 → 採用
- **Stripe Dashboard**：高密度情報、清潔さ → 参考
- **Bloomberg/Koyfin**：投資UI文法 → 採用

### このツールの独自ポジション
「**保有資産管理ツール**」ではなく「**次の判断を支援するツール**」。
既存の投資UIから外れた設計が必要だった。
ダッシュボードの主役を「売り買いレコメンド」にすることで、このポジションを明確化。

## 9. STEP B で確定した重要な設計判断

設計を進める中で得た「他の画面でも貫くべき原則」：

1. **時間軸の正確性 > 統一の美しさ**
   - 銘柄ごとに目標期間が違うなら、グラフも別々に描く
   - 「揃ってる方が綺麗」だが、情報の意味を歪めてはいけない

2. **主役と脇役の明確化**
   - 売り買いが主役、他は脇役
   - 脇役を主役と同等に並べると、本当に大事なものが埋もれる

3. **状態の色分けは縦に揃える**
   - 5銘柄を3カラムで並べた時、状態の色（緑/黄/赤）が縦に並んで一目で識別できる
   - 「全銘柄を見る前に、注意すべき銘柄が分かる」

4. **AIの判断の透明性**
   - トピックス → どのニュースを読んだか
   - 影響表示 → そのニュースがどのレコメンドに紐付くか
   - シナリオ進捗 → なぜ今売り/買いなのか
   - これらが揃って、ブラックボックス感が消える

5. **規律の構造化**
   - 損切りラインを赤の水平線で明示
   - 「FXで感情に振られた経験」を売り推奨の文脈で言及
   - 機械的な判断を促す UI 設計

6. **「完璧ではない」の禁止**
   - 改善余地を最後に並べると、せっかくの完成度が霞む
   - 完成形を提示し、率直な指摘を待つ姿勢で進める
