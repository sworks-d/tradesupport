# ロードマップ：攻守の専門家 → GENDO統合 → ペーパー運用（revised 2026-05-25）

壁打ちの結論を反映した改訂版。**蠱毒は「勝者を選ぶ」でなく「攻めを最適化・守りを検証」で攻守を鍛える道具**。
ただし歴史の蠱毒(P2)はPIT依存・多重比較・守り過適合のリスクが大きく、**クリティカルパスから外す**。
前向きペーパーがPIT問題を消し、守りをフル稼働で前向きOOSに入れる最善手。

## 不変の原則（この計画の土台）
- 稼ぎ＝所有×時間×複利（β）。攻め（予測α）は液体大型で無エッジと実証済。
- **線は攻守でなく「価格/財務」で引く**：価格信号(モメンタム/相対力/DD/value-trap/集中/stop)は歴史で先読みなし検証可。財務(M/F/Z・V字EPS・健全性)はPITが要る＝歴史検証は後回し。
- **攻め=最適化／守り=検証**。守りのエッジは会計論理（粉飾を持たない）＝閾値は論理で固定し、蠱毒は「破綻せず誤爆しないか」の検証に留める。最適化すると論理フィルタがノイズ当てに退化する。
- 決裁は人間（原則2）。GENDOは推奨＋反対論拠を出して支えるが決めない。総合スコアは出さない（原則3）。

## 最小クリティカルパス（価値の大半は守り＋規律＋紙で出る）
1. **P4-1 紙執行ループ（守り主導）** ← 着手中。approved→サイジング→**翌寄り**紙約定→Portfolio→record_entry。
2. **P4-2 Core-Satellite配分**：コア=守り検品生存の質分散塊。
3. **P4-3 一気通貫 run_paper.py**：監視=毎営業日／コア積立=**月次DCA**（既定）。
4. **P4-4 評価（守りはリターンで測らない）**：①コアが自爆せず質パッシブに追随 ②プロセス遵守（利確しない・狼狽売りしない）。攻め/裁量は前向き較正。
5. 並走開始（攻めは**情報のみ・枠0**／裁量サテライトは**死ぬサイズ**・ただし前向きに記録評価）。
6. （後日）PIT財務 → 守りの**検証**蠱毒(P2-2)＋攻めの本格較正。

## 攻めの昇格条件（pre-commit＝未練を規律に変える）
攻めは「情報のみ・枠0」から、前向きペーパーで**全部**満たした時だけサテライト枠（まず5%）へ：
1. 攻めフラグ銘柄の前向き決済 ≥30件（見始める門。信じる閾ではない＝95%CI±18%）。
2. **コントロール参戦に有意差で勝つ**：同一銘柄・同期間・同出口の「ランダム/全日エントリー」を上回る（＝β/払戻比でなくαの分離）。※払戻比突破(勝率>37.5%)は必要だが不十分。
3. 上げ・下げ両局面（≥2四半期）で正、かつ**nが増えても差が持続**。
満たすまで攻めは1円も張らない。満たしたら少枠から逓増。

## 蠱毒の鉄則（PIT解決後に歴史で回す時）
OOSで戦う／適応度は実行前に固定（後付け禁止）／変異体数に上限／窓ごと最小サンプル下限／全窓頑健（1窓勝者は失格）／**守りは最適化せず検証のみ／buy&hold質コアを常に基準参戦**。

## 設計確定（P4）
- 紙約定価格＝**翌営業日の寄り**（先読み回避）。
- 監視＝毎営業日／コア積立＝**月次DCA**（既定・設定可）。
- 会計分離：①システム攻め=0円 ②裁量サテライト=死ぬサイズ（前向き記録評価）。
