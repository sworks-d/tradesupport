**役割（要件）**：自前実装に固執せず、`virattt/ai-hedge-fund`・`TradingAgents` 等から**使える部品を借りて**
本パイプラインの穴（特に評価/バックテスト/データ接続）を埋める。**現状＝未着手0%。**
**全体ゴール寄与**：車輪の再発明を避け、評価基盤や文脈解釈の質を底上げする。
**前からの引き継ぎ**：本spec群（どのPに穴があるか）。**次への引き渡し**：借用部品（各Pに統合）。
**ハルシネ防止方針**：借りても**不変原則は曲げない**（数値はコード／総合スコア出さない／決裁は人間）。
借用コードがLLMに数値生成させる作りなら、本プロジェクト原則に合わせて改修してから取り込む。
