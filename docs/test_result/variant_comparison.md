# リスク姿勢3パターン × 予算別 バックテスト比較

実行日 2026-05-25 ／ universe=現20銘柄(生存) ／ 期間 2016-08-15〜2026-05-25(10y) ／ エントリ=GC(20/60)固定 ／ 出口=固定stop＋保有期限120d(B') ／ 再現：`scripts/variant_backtest.py`

## パターン定義（中のパラメータ＝姿勢ノブ）
- **基本**：risk/trade=2%・現金下限=20%・1銘柄上限=20%・stop=12%・枠=5・core/sat=85%/15%
- **強気**：risk/trade=3%・現金下限=10%・1銘柄上限=30%・stop=15%・枠=4・core/sat=70%/30%
- **守り**：risk/trade=1%・現金下限=30%・1銘柄上限=12%・stop=10%・枠=8・core/sat=95%/5%

## 読み取り（¥100万・忖度なし）
- Sharpe最良＝**守り**（+1.39）／総リターン最良＝**基本**（+345%）／最小DD＝**守り**（-16%）。
- いずれの姿勢も buy&hold（+1845%）に届かない＝エントリーにエッジが無い（姿勢ノブはαを生まない）。姿勢が効くのは主に**DD/Sharpe＝リスク側**。守りはDDを抑え、強気はDDを膨らませる。

## バイアス申告
- survivorship bias（現銘柄=生存者）／コスト未控除（強気は高回転で悪化）／単一期間／core-satellite比率は本BT(単一スリーブGC)では未行使（DDは主に risk%・stop・枠で決まる）。

## 判定
- 3姿勢とも『タイミングで勝つ』形ではαが出ない。**選ぶべきは『どれだけ稼ぐ姿勢か』でなく『どれだけDDに耐える姿勢か』**。哲学（持ち続け・自爆しない）に最も合うのは守り〜基本側。強気は同じ無エッジ下でDDだけ増やす＝不利。
